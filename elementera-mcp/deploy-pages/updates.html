安装与签名

debug APK 只用于测试；unsigned release APK 不能直接安装。覆盖安装需要相同 packageName、相同签名，并递增 versionCode。长期 release keystore 必须保存在私有离线位置，不应提交到 GitHub。

APP 内可从右上角原生菜单选择“检查 APP 更新”。检查只在点按时发生，不自动下载、不自动安装，也不会强弹窗。
